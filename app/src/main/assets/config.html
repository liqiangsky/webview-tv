开发者调试

拦截图片/字体
不加载网页的图片和字体（CSS 照常加载，版式不受影响）。 站点排版错乱、播放器起不来时先关它试试，关掉就是原样渲染。
脚本本地缓存
把网页 JS 存到本地复用，二次进台免下载。怀疑缓存了旧脚本、或想让页面 完全按线上最新代码跑时关掉它。
视频状态浮层
屏幕左下角叠一层文字，显示页面里每个 video 的地址与播放状态， 排查「没画面」时用。
几何调试
全屏容器画青色边框、视频画粉色内描边，并每秒往日志里打一行实际几何值 （容器/视频矩形、视口、缩放、屏幕像素），用来分辨「没铺满」还是「画面偏了」。
四个开关都即时生效：前两项下一次请求就按新值走；浮层和几何标记在播放画面上 当场出现/消失，不用重启也不用切台。它们只影响这台电视的播放，不改变频道数据。

脚本接口

什么时候跑
脚本只跑在你点名绑定它的那个频道上；没绑定脚本的网页，页面里根本没有 TV。 同一段脚本会被反复执行，下面四种时机各跑一次：
① 页面加载完、DOM 建好；
② 播放器铺满屏幕那一刻；
③ 页面地址变了（站内换路由、同页跳转，每秒查一次）；
④ 你自己用 TV.repeat(ms) 定的节奏。

所以脚本要能重复跑：只登记状态，有副作用的动作放进 TV.once 或自己的标记里。 脚本抛的异常会被吞掉并记一行「脚本异常」，不会影响播放。
接口7 个
TV.holdCover()
要开始页内切台了：先把黑幕压住，切的过程中不露旧画面和半成品。
TV.afterSwitch()
切完了：放开黑幕，应用重新接管全屏和播放，新流真的出首帧才渐显。 压太久（起播超时）会被强制放开并记一行日志。
TV.click(el)
先滚到可见再 click()，返回 true/false。 元素为空或点的时候抛错都只记日志，不会把异常抛回页面。
TV.once(key, fn)
同一个页面文档里只跑一次，适合初始化。页面重新加载后重新算，不是整个应用只一次。
TV.repeat(ms)
让应用每隔 ms 再执行一次脚本（200–60000），传 0 停。 站点渲染慢、自己换路由时不用干等上面那几种时机；重新加载页面后要重新设。
TV.log(m)
往运行日志写一行，频道行点「日志」能看到。排查脚本就用它， console 不会进日志面板。
TV.toast(m)
在电视屏幕底部提示一句，两秒后自己消失。
例子
// 一个网页里有很多频道：每个频道一条地址、只差 URL 参数，都绑这一段脚本；
// 脚本读参数，自己去点该选的那一路
var ch = new URLSearchParams(location.search).get('ch');   // 换成你的参数名
if (ch != null) {
  TV.holdCover();
  var ok = TV.click(document.querySelector('换成第 ' + ch + ' 项的选择器'));
  TV.log('切到第 ' + ch + ' 路：' + (ok ? '已点击' : '没找到入口'));
  // 等页面把新流接上再放开，否则揭幕时可能还是旧画面
  setTimeout(TV.afterSwitch, 800);
} else {
  TV.log('地址里没有参数，按页面默认的频道播');
}
注意
页面标题不可靠：很多站换台后 title 不变，判断「真的换了」要看画面或自己在脚本里记的状态， 别只看 title。

换一路就是重新加载一次页面（重新拉流、重新静音起播），比页内点一下慢；脚本要尽快点完、尽快 TV.afterSwitch()，别把黑幕压太久。

起播阶段应用会把页面静音，等画面落定才开声；脚本不用管声音，也别拿「有没有声音」判断播没播起来。
